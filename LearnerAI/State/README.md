# State Module

State stores information that must survive the current rule pass.

## Owns

- strategic posture representation;
- persistent demand state;
- deliberate transitions;
- genuinely required execution memory;
- controlled timers.

## Product rule

Most facts should remain derived.

State is justified only when current engine facts, direct rule order, or an existing demand cannot express the required behavior.

Read LearnerAI/OWNERSHIP.md, SCHEMAS.md, LIFECYCLE.md, and docs/audits/Basilisk-Removable-State-Audit-2026-09.md.

## Boundary

State represents decisions and execution lifecycle.

It does not invent strategy.
