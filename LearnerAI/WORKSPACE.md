Each module will eventually contain focused lesson specifications and, later, implementation files. This phase deliberately contains no gameplay code.

## Reserved curriculum artifacts

- lesson specifications
- verified AIRef command references
- verified identifiers
- rule-order diagrams
- demand/capability/action/witness examples
- static validation checklists
- runtime test matrices
- failure and recovery exercises
- Byzantine-specific examples
- community-pattern comparison notes

## Non-goals

Do not turn this into a generic manager framework, scheduler, simulator, or Basilisk clone. The purpose is to teach real AoE2 engine behavior and community-native scripting patterns.
