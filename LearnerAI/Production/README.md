# Production Module

Production converts legitimate demand into executable queues.

## Owns

- villager production;
- military-unit production;
- technology production;
- production-building capability;
- queue state;
- current plus queued counts;
- completion witnesses.

## Product rule

Production capacity follows current demand.

The player should not build production buildings because the strategy name says so. It builds them because standing requirements and replacement rates require capacity.

## First competitive target

Do not overproduce Feudal military.

Maintain a defensible standing floor, then increase capacity when actual military demand requires it.
